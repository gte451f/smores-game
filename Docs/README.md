# Documentation

Permanent design and system documentation lives in `.claude/skills/` (`game-design` for
aspirational/intent-level design, `game-systems` for implemented systems and the player
surface). This folder holds the temporary working documents instead:

- `roadmaps/` — multi-step implementation plans (`*-roadmap.md`), one heading per slice.
  They are working documents, not reference: read one only while implementing a slice from
  it, or when Jim points at it. When a slice ships, what it built is written into the
  matching `game-systems` topic and trimmed out of the roadmap, so a roadmap keeps only the
  work still ahead plus its status list and Resolved Design Decisions log. Once every slice
  is done the file is historical reference only and is not maintained.
- `Notes.md` — scratch notes.
