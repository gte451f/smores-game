# Main Menu and Meta-Flow

**Status:** placeholder — not yet designed.

Will cover the screens a player moves through outside an active campaign: title screen,
new-game setup (scenario/starting-squad selection, difficulty and modifier picks — see
`difficulty-and-modifiers.md`), continue/load (see `save-system.md` for what a save
contains), the options menu's structure (as distinct from `player-experience.md`'s
settings *content*), credits, and an announcements/news surface (patch notes, live-service-
style messaging).

## Open Design Questions Worth Tracking

- Whether announcements are purely in-game text or imply any live backend.
- How new-game setup and the tutorial/scenario start (`tutorial-and-scenario-start.md`)
  hand off to each other.
- Whether options menu structure differs meaningfully from a flat settings list.
